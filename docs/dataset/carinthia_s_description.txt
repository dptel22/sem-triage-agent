Abstract
The
Carinthia-S dataset
is an enhanced version of the original publicly available Carinthia dataset
[1]
, augmented with expert-validated binary segmentation masks for each defect image. It contains Scanning Electron Microscope (SEM) images of defects observed on a single production layer of unstructured semiconductor wafers, along with their corresponding segmentation masks. The dataset comprises 4,591 images, each paired with a segmentation mask, unevenly distributed across six defect classes.

Class distribution of the Carinthia-S dataset
Figure 1
shows the defect class distribution of the
Carinthia-S
dataset. The y-axis depicts the six different defect classes and the x-axis the number of images. This bar chart shows that the dataset is highly imbalanced.
Figure 1: Defect class distribution of the dataset.
Image examples of all defect classes
Figure 2
provides representative examples of all six defect classes. The defect classes are listed in the first column, while the remaining 14 columns display randomly selected example images along with their corresponding masks for each class. For defect class ‘5’, which contains only four images, all available images are shown, leaving the remaining columns blank. In images associated with defect class ‘6’, no visible defects are observed. Such images may arise during production when the SEM tool is misaligned. In these cases, the tool may capture images of regions adjacent to the defect instead of the defect itself.
Figure 2: Example images of all classes.
